# Project instructions

Applies to this repository. These instructions override the IDE-global defaults found in `IDE-AGENT.md` / `~/.config/opencode/AGENTS.md` when they conflict.

## Stack & Environment

- **Language/Framework**: Markdown, Shell, Bash, YAML (Prompt & Skill Configuration Repository)
- **Primary Directories**:
  - `skills/`: Repository of core engineering workflows
  - `agents/`: Reviewer and auditor personas

## Development Conventions

- All skills must maintain a standard layout and structure (`SKILL.md`).
- Ensure any additions or changes to skills are fully tested, logically consistent, and language-agnostic.
- Optimize prompts for minimal context usage and high clarity.
